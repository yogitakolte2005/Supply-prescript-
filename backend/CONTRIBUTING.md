# Backend Contribution Guidelines

## Development Standards

- Follow Python naming conventions.
- Keep API routes organized and readable.
- Use environment variables for application configuration.
- Add tests when introducing new backend functionality.
- Keep dependencies updated in requirements.txt.

## Git Workflow

1. Create or switch to the appropriate feature branch.
2. Make focused changes.
3. Test the changes before submitting.
4. Use clear and descriptive commit messages.
5. Push changes to the remote repository.

## Code Quality

- Avoid committing virtual environments.
- Do not commit .env files or credentials.
- Keep documentation updated when API behavior changes.
