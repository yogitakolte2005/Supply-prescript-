# SupplyPrescript

SupplyPrescript is a planned prescriptive analytics application for supply-chain decision support. The goal is to connect delay predictions and optimization recommendations with a dashboard where users can review and execute decisions.

## Planned Architecture

- **Backend:** FastAPI and Python REST APIs.
- **Database:** PostgreSQL for decision records and history.
- **Frontend:** React dashboard with Tailwind CSS.
- **Integration:** Connect prediction and optimization outputs to the backend and dashboard.
- **Deployment:** Document and validate the application startup and deployment process.

These components are planned; implementation and integration will be completed incrementally.

## Member 2 Responsibilities

- Develop backend APIs using FastAPI.
- Configure PostgreSQL connectivity and decision-history storage.
- Build the React dashboard and visualizations.
- Integrate backend responses with the dashboard.
- Implement decision execution and database write-back.
- Test, document, and prepare the application for deployment.
